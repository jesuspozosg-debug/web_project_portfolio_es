# Portfolio Web de Mariana Hernández

## Descripción

Proyecto del Sprint 4 de TripleTen. Portfolio personal responsive desarrollado con HTML y CSS siguiendo la metodología BEM. El sitio es adaptable a dispositivos móviles, tablets y escritorio.

## Tecnologías y técnicas utilizadas

- _HTML5_: Estructura semántica
- _CSS3_: Flexbox, Grid, Media Queries
- _Metodología BEM_: Nomenclatura de clases organizada
- _Responsive Design_: Breakpoints en 320px, 768px, 1024px
- _Git & GitHub_: Control de versiones
- _GitHub Pages_: Deploy del proyecto
